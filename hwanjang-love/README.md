# 환장연애 (EXChange) — 현실 연애 솔루션 & 안전 상담소

제공된 **'환장연애' 로고 이미지(깊은 버건디/레드 & Dusty Teal, 환승 노선도 메타포, 고운 바탕 클래식 서체)**를 기반으로 리뉴얼된 블로그 게시판 메인 UI 및 **Supabase 데이터베이스 연동** 애플리케이션입니다.

## ⚡ Supabase 데이터베이스 연동 안내

### 1. `stories` 테이블 생성 SQL (Supabase SQL Editor에서 실행)

```sql
-- 1. stories 테이블 생성
create table public.stories (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  content text not null,
  password text not null default '1234',
  category text not null default 'spicy', -- 'spicy' 또는 'sos'
  is_secret boolean default false,
  author text default '익명 사연자',
  counselor text default '냉정한 팩폭러',
  counselor_avatar text default '⚡',
  prescription text,
  reactions jsonb default '{"flame": 0, "tear": 0, "soda": 0}'::jsonb,
  comments jsonb default '[]'::jsonb
);

-- 2. Row Level Security (RLS) 활성화 및 누구나 읽기/쓰기 허용 (기본 정책)
alter table public.stories enable row level security;

create policy "Enable read access for all users"
on public.stories for select
using (true);

create policy "Enable insert access for all users"
on public.stories for insert
with check (true);

create policy "Enable update access for all users"
on public.stories for update
using (true);

create policy "Enable delete access for all users"
on public.stories for delete
using (true);
```

### 2. `app.js`에 내 Supabase Key 연결하기

[`app.js`](app.js) 최상단의 `YOUR_SUPABASE_URL`과 `YOUR_SUPABASE_ANON_KEY`를 본인 프로젝트의 값으로 변경하세요:


## 🛡️ 핵심 기능
1. **카테고리 탭 분리**:
   - `🔥 매운맛 썰 (일반 하소연)`: Dusty Teal 색상 활성화
   - `🚨 SOS 안전 상담소 (진지한 고민/도움 요청)`: Burgundy/Red 색상으로 활성화

   - `🔒 나만 보기 (비밀글)` 토글 스위치 & `🔑 비밀번호 4자리` 인증 모달
3. **사연 상세 모달 & 💬 댓글 시스템 & ✏️ 수정 / 🗑️ 삭제**:
   - 상세 모달에서 실시간 댓글 등록 및 4자리 PIN 기반 수정/삭제

   - 화면 좌측 하단 고정 원터치 연결
